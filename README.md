# Misc sites

This repository is published with GitHub Pages. The root `index.html` is the directory page. Each subfolder is an independent site and must contain its own `index.html`.

## Sites

- `july4-menu/` — A Declaration of Courses, available at `/july4-menu/`
  - `july4-menu/recipes/` contains the source recipe notes.

## Add a site

1. Create a folder named for its URL, for example `weather/`.
2. Add `weather/index.html`.
3. Add a link to `weather/` in the root `index.html`.

GitHub Pages will publish that site at `https://patcao.github.io/misc/weather/` when Pages is configured to deploy from the repository root on the published branch.
